# Бриф: Pepl Downloader (трей-приложение для Windows)

## Суть
Лёгкое приложение для Windows, которое живёт в системном трее. По горячей клавише или клику по иконке появляется компактное окно в стиле Spotlight/Raycast: вставляешь ссылку на YouTube или любой другой сервис, выбираешь формат и качество, жмёшь «Скачать». Загрузки идут в фоне, через очередь.

## Стек
- **Оболочка:** Tauri 2 + React + TypeScript (Vite). Стили: Tailwind или CSS-модули, на выбор разработчика.
- **Движок:** `yt-dlp` (запускается как отдельный процесс/sidecar) + `ffmpeg` для склейки, конвертации, обрезки и вшивания метаданных.
- **JS-рантайм для yt-dlp:** с конца 2025 года yt-dlp нужен внешний JS-рантайм (рекомендуется Deno), без него YouTube работает не полностью. Предусмотреть это при упаковке.
- **Хранение:** настройки и история в JSON или SQLite в `%APPDATA%\<app>`.
- Целевая ОС: Windows 10/11 (x64).

## Поведение в системе
- Иконка в **системном трее**, приложение работает в фоне.
- **Глобальная горячая клавиша** открывает и закрывает окно. По умолчанию, например, `Ctrl+Alt+D`, меняется в настройках.
- Клик по иконке в трее открывает окно. Правый клик открывает меню: Открыть / Загрузки / Настройки / Выход.
- **Автозапуск с Windows**: переключатель в настройках, приложение стартует свёрнутым в трей.
- Закрытие окна (Esc, клик мимо, потеря фокуса) только **прячет** его. Процесс и загрузки продолжают работать.
- Повторный запуск .exe не создаёт второй экземпляр, а показывает окно уже запущенного (single instance).

## Окно (UI)
- **Стиль:** без рамки, по центру экрана, скруглённые углы, эффект Mica/Acrylic, **только тёмная тема**, **интерфейс на русском**.
- **Начальное состояние:** одно поле ввода «Вставьте ссылку…» с фокусом.
- **Автовставка из буфера:** если при открытии окна в буфере обмена лежит URL, он сразу подставляется в поле и запускается анализ.
- После ввода ссылки окно **плавно растёт вниз** и показывает:
  1. **Превью:** обложка, название, канал, длительность. Пока yt-dlp получает данные, показывается скелетон-загрузка.
  2. **Формат** (дропдаун):
     - Видео: MP4, MKV, WebM
     - Аудио: MP3, M4A, OPUS, FLAC, WAV
  3. **Разрешение/качество** (дропдаун): только варианты, реально доступные для этого видео (2160p/1440p/1080p60/720p/…), с примерным размером файла. Для аудио здесь выбирается битрейт.
  4. **«Для продвинутых»** (раскрывающийся блок): полная таблица потоков, как в `yt-dlp -F` (id, контейнер, кодек, разрешение, fps, битрейт, размер). Можно выбрать конкретный видео- и аудиопоток вручную.
  5. **Опции:**
     - ☐ Скачать весь плейлист (показывается, только если ссылка содержит плейлист; **по умолчанию выключено**, качается одно видео). Желательно дать выбрать отдельные видео из плейлиста.
     - ☐ Субтитры: выбор языков, «вшить в файл» или «отдельным .srt», учитывать автосубтитры.
     - ☐ Обложка и метаданные в файл (по умолчанию включено для аудио).
     - ☐ Обрезка по времени: поля «с» / «до» (формат `мм:сс` или `чч:мм:сс`).
     - ☑ **Скачивать в папку по умолчанию** (см. ниже).
  6. Кнопка **«Скачать»**. Enter тоже запускает скачивание.

### Чекбокс «Скачивать в папку по умолчанию»
- Состояние **запоминается** между запусками.
- Папка по умолчанию: системная `Downloads` (`FOLDERID_Downloads`, не захардкоженный путь). В настройках её можно сменить на любую.
- Галка **включена**: файл сразу уходит в очередь и качается в эту папку.
- Галка **выключена**: после нажатия «Скачать» открывается системный диалог «Сохранить как» / выбор папки, и только потом задача попадает в очередь.

## Очередь загрузок
- Можно добавлять ссылки одну за другой, не дожидаясь окончания предыдущих.
- Параллельно идёт N загрузок (по умолчанию 2, настраивается), остальные ждут.
- У каждой задачи: обложка-миниатюра, название, прогресс-бар, скорость, ETA, статус (в очереди / загрузка / обработка ffmpeg / готово / ошибка).
- Действия: пауза/продолжить (если поддерживается), отмена, повтор при ошибке, «Открыть файл», «Показать в папке».
- Очередь доступна в окне (вкладка или панель «Загрузки» под полем ввода) и из меню трея.
- По завершении приходит **уведомление Windows** (toast). Клик по нему открывает файл или папку.
- Иконка в трее показывает, что идут загрузки (бейдж или анимация, тултип с общим прогрессом).

## История загрузок
- Список скачанного: дата, название, источник, формат, путь.
- Кнопки: открыть файл, показать в папке, скопировать ссылку, скачать снова, удалить из истории.
- Поиск по истории, кнопка «Очистить историю».

## Настройки
- Папка по умолчанию.
- Горячая клавиша.
- Автозапуск с Windows.
- Число параллельных загрузок.
- Шаблон имени файла (по умолчанию `%(title)s.%(ext)s`, с подсказками по переменным).
- Формат и качество по умолчанию (что выбрано сразу после вставки ссылки).
- **Cookies:** выбор браузера (Firefox / Chrome / Edge / Brave / нет) для `--cookies-from-browser` **или** путь к `cookies.txt`.
  Важно: в новых версиях Chrome/Edge на Windows из-за app-bound encryption извлечение cookies часто не работает. Firefox работает надёжно, а `cookies.txt` нужен как запасной вариант. Это стоит показать подсказкой в UI.
- Прокси (необязательно, одно поле).
- Версия yt-dlp, кнопка «Проверить обновление».

## Обновления
- **yt-dlp:** автоматически проверяется при старте (не чаще раза в сутки) и обновляется в фоне. Это критично: YouTube регулярно ломает скачивание.
- **Само приложение:** через Tauri updater с релизами на GitHub (подписанные обновления).

## Зависимости при первом запуске
- Варианты для разработчика (выбрать один):
  - а) класть `yt-dlp.exe`, `ffmpeg.exe` (+ deno) в установщик как sidecar-бинарники;
  - б) при первом запуске скачивать их в `%APPDATA%\<app>\bin` с прогрессом («Подготовка…»). Установщик тогда маленький, обновлять проще.
- Рекомендация: yt-dlp и deno скачивать и обновлять в `%APPDATA%` (их нужно часто обновлять), ffmpeg можно положить в установщик.

## Обработка ошибок
- Невалидная ссылка или неподдерживаемый сайт: понятное сообщение прямо под полем.
- Видео 18+, приватное или только для подписчиков: сообщение с подсказкой включить cookies в настройках.
- Нет сети, ошибки yt-dlp: показать короткий текст ошибки и кнопку «Подробнее» (полный лог).
- Если ошибка похожа на «сломался экстрактор», предложить обновить yt-dlp.
- Лог-файл в `%APPDATA%\<app>\logs`.
