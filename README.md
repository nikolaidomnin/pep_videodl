# Video Downloader

Лёгкое трей-приложение для Windows, чтобы быстро скачивать видео и аудио: нажал горячую клавишу,
вставил ссылку на YouTube (или любой из 1000+ сайтов, которые поддерживает yt-dlp), выбрал формат и качество, скачал.

![иконка](src-tauri/icons/128x128.png)

## Зачем

`yt-dlp` умеет почти всё, но это консольная утилита: надо помнить ключи, ставить ffmpeg,
следить за обновлениями. Сайты-качалки полны рекламы и ограничений. Это приложение — тонкая и
быстрая оболочка над `yt-dlp` в стиле Spotlight/Raycast:

- всегда под рукой (живёт в трее, открывается горячей клавишей);
- ничего не нужно ставить руками: инструменты скачиваются и обновляются сами;
- показывает только реально доступные для видео форматы и разрешения с размером файла;
- умеет обрезать видео до кадра, качать плейлисты и держит очередь загрузок.

## Возможности

- Окно в стиле Spotlight: одно поле ввода, растёт вниз после вставки ссылки. `Esc` или клик мимо прячут его.
- Глобальная горячая клавиша (`Ctrl+Alt+D` по умолчанию, меняется в настройках), клик по иконке в трее, меню трея.
- Если в буфере обмена лежит ссылка, она подставляется автоматически.
- Превью: обложка, название, канал, длительность.
- Форматы: MP4, MKV, WebM, MP3, M4A, OPUS, FLAC, WAV. В аудио вшиваются обложка и метаданные.
- Разрешения берутся только те, что реально есть у видео, с примерным размером файла.
- Плейлисты: галка «Скачать весь плейлист» и список видео с чекбоксами, чтобы выбрать только нужные.
- Обрезка: ползунки «начало / конец» с таймкодами `ММ:СС:КК` (до кадра), ручной ввод, стрелки по кадру (Shift — по секунде),
  предпросмотр кадров: при перетаскивании миниатюра из раскадровки YouTube, после — точный кадр через ffmpeg прямо из потока.
- Очередь: одновременно качаются 2 файла, остальные ждут. Прогресс, скорость, ETA, отмена.
- Сохранение в папку по умолчанию или через «Сохранить как».
- Уведомление Windows по завершении, кнопки «Открыть» и «В папке».
- Автозапуск вместе с Windows (галка в настройках): приложение стартует свёрнутым в трей.
- Один экземпляр: повторный запуск .exe просто показывает окно.
- Темы оформления: встроенная «Стандартная», остальные скачиваются из [каталога тем](https://github.com/nikolaidomnin/videodl-themes)
  («Настройки → Скачать темы…»). Тема — это только данные (JSON и картинки/видео), никакого кода.

## Установка

Скачайте установщик `Video Downloader_x.y.z_x64-setup.exe` (или `.msi`) и запустите.
Права администратора не нужны: приложение ставится для текущего пользователя.

- Нужна Windows 10/11 x64 и WebView2 (в Windows 11 уже есть; в Windows 10 установщик докачает его сам).
- При первом запуске приложение скачает `yt-dlp`, `deno` и `ffmpeg` (если его нет в `PATH`) в
  `%APPDATA%\com.nikol.videodl\bin`. Это пара сотен мегабайт (больше всего весит ffmpeg), один раз.
- Сборка не подписана, поэтому Windows SmartScreen может предупредить: «Подробнее → Выполнить в любом случае».

## Как это устроено

```
┌──────────── окно (WebView2) ────────────┐        ┌────────── процессы ──────────┐
│ React + TypeScript                      │ invoke │ yt-dlp  → информация, загрузка│
│ поле ссылки, превью, опции, очередь     │ ─────► │ ffmpeg  → склейка, обрезка,   │
│                                         │ ◄───── │           конвертация, кадры  │
└─────────────────────────────────────────┘ events │ deno    → JS-рантайм для yt-dlp│
        Rust (Tauri): трей, горячая клавиша,       └───────────────────────────────┘
        окно, очередь, настройки, загрузка инструментов
```

- **Интерфейс** — React-приложение внутри системного WebView2. Окно без рамки и прозрачное, высота подстраивается под содержимое.
- **Ядро** на Rust (Tauri): трей, глобальная горячая клавиша, показ и скрытие окна, очередь загрузок, настройки,
  скачивание и обновление инструментов, каталог тем. Фронтенд вызывает его командами (`invoke`), а прогресс получает событиями.
- **yt-dlp** запускается отдельным процессом: `-J` для информации о видео и плейлисте, загрузка с
  `--progress-template` — Rust разбирает его вывод и шлёт прогресс в окно. Раз в сутки `yt-dlp` обновляется в фоне.
- **ffmpeg** нужен yt-dlp для склейки видео и аудио, перекодирования в нужный формат, обрезки (`--download-sections`)
  и вшивания обложки; приложение само дёргает его для точного кадра в предпросмотре обрезки.
- **Deno** — с конца 2025 года YouTube требует JS-рантайм для расшифровки ссылок на потоки, `yt-dlp` находит его в `PATH`.
- Настройки лежат в `%APPDATA%\com.nikol.videodl\settings.json`, скачанные темы — в `...\themes`.

## Технологии

| [FFmpeg](https://ffmpeg.org) (сборка [BtbN](https://github.com/BtbN/FFmpeg-Builds)) | Склейка, конвертация, обрезка, обложки, кадры для предпросмотра. |
| [Deno](https://deno.com) | JS-рантайм, который нужен yt-dlp для YouTube. |
| tokio, reqwest, zip | Асинхронные процессы, загрузка инструментов и тем по HTTPS, распаковка архивов. |

## Разработка

Нужны Node 20+, Rust (`winget install Rustlang.Rustup`) и Visual Studio Build Tools с компонентом «Разработка классических приложений на C++».

```bash
npm install
```

```bash
npm run tauri dev
```

Сборка установщиков (NSIS `.exe` и `.msi` появятся в `src-tauri/target/release/bundle`):

```bash
npm run tauri build
```

Иконки генерируются из одной картинки (PNG 1024×1024 или SVG):

```bash
npx tauri icon path/to/icon.svg
```

### Структура

- `src-tauri/src/lib.rs` — трей, горячая клавиша, окно, автозапуск, команды для фронтенда.
- `src-tauri/src/ytdlp.rs` — информация о видео и плейлистах, скачивание с прогрессом, кадры через ffmpeg.
- `src-tauri/src/deps.rs` — поиск, загрузка и обновление yt-dlp / ffmpeg / deno.
- `src-tauri/src/settings.rs` — настройки в `%APPDATA%\com.nikol.videodl\settings.json`.
- `src-tauri/src/themes.rs` — каталог тем: список, скачивание, удаление.
- `src/App.tsx` — главный экран; `src/components/*` — превью, опции, обрезка, очередь, настройки; `src/themes/` — применение тем.
- [BRIEF.md](BRIEF.md) — исходный бриф и план этапов.

## Темы оформления

Тема — папка с `theme.json` и медиа рядом. Приложение скачивает темы из каталога в
`%APPDATA%\com.nikol.videodl\themes\<id>\` (туда же можно положить тему вручную).

### Каталог тем

Репозиторий, адрес которого задан в `CATALOG_BASE` (`src-tauri/src/themes.rs`). В корне `index.json`:

```json
{
  "themes": [
    { "id": "ocean", "name": "Океан", "author": "я", "description": "Видеофон с волнами", "version": 1, "zip": "themes/ocean.zip" }
  ]
}
```

- `id` — имя папки темы (латиница, цифры, `-`, `_`), `zip` — путь к архиву от корня репозитория. В архиве `theme.json` лежит в корне или в одной вложенной папке.
- Чтобы выпустить обновление, увеличьте `version`: у установленной темы появится кнопка «Обновить».
- Для проверки адрес каталога можно подменить переменной окружения `VIDEODL_THEMES_URL`.

### theme.json

```json
{
  "name": "Океан",
  "author": "я",
  "scheme": "dark",
  "colors": { "bg/base": "#0c1a24", "accent/default": "#3ec7c2", "text/dim": "#8fb3c4" },
  "radius": { "panel": 16, "control": 8 },
  "background": { "video": "loop.webm", "poster": "poster.webp", "opacity": 0.6 }
}
```

- `colors` — любые токены из `src/themes/index.ts` (имена совпадают с переменными в Figma); не указанные берутся из стандартной темы.
- `background`: `image` (png/webp/jpg/svg), `video` (webm), `poster` (первый кадр), `tile` (замостить), `opacity` (0–1), `gradient` (CSS-градиент).
- `frame` — картинки вокруг окна: `images` (набор png/webp/svg, для каждого места берётся случайная),
  `margin` (поле вокруг панели, px), `spacing` (шаг вдоль края), `edgeSpacing` (шаг сверху и снизу), `size` ([мин, макс]), `sideSize` (размер по бокам, если нужен другой), `overlap` (насколько заходят на панель),
  `tilt` (наклон, °), `float` ({ `amplitude` px, `duration` с } — левитация и покачивание). Чем выше окно, тем больше картинок по бокам.
  `frame.sparkles` — { `images`, `spacing`, `size` }: блёстки прямо на линии края панели, вспыхивают и гаснут.
- `stickers` — картинки, приклеенные к углу панели. Поля: `image`, `anchor`
  (`top-left` / `top-right` / `bottom-left` / `bottom-right` или середина стороны: `top-center` / `bottom-center` / `left-center` / `right-center`), `x` и `y` (центр картинки от угла, px), `width`,
  `rotate`, `flip`, `opacity`, `layer` (`back` — на фоне под содержимым, `under` — снаружи под панелью, `front` — поверх края панели),
  `minHeight` / `maxHeight` (показывать, только если панель не ниже / не выше, px), `twinkle` (мерцать), `float` (левитировать).
- `decor` — маленькие украшения в интерфейсе: `title` (после «Настройки»), `label` (после подписей полей), `activeCard` (на выбранной теме).
- `effects` — `glow` (неоновое свечение, px; цвета — токены `glow/panel`, `glow/control`, край панели — `border/panel`), `gloss` (блик на кнопках и полях, 0–1),
  `fieldBorder` (2–5 цветов: рамка полей ввода с переливом). Цвета вторичных кнопок — токены `button/secondary`, `button/secondary-hover`, `button/secondary-text`.
- `radius.button` — скругление кнопок и полей (999 — «таблетки»).
- `panelFrame` — рамка вокруг панели (9-slice): `image`, `slice` ([верх, право, низ, лево], px картинки), `outset` (сколько выходит за край панели), `scale` (0.5 для @2x).
- `button` — главная кнопка-картинка («Скачать»), `buttonSecondary` — остальные кнопки: `image`, `margins` ([верх, право, низ, лево] — прозрачные поля, px картинки),
  `slice` (ширина неизменяемых краёв, px), `text` (цвет надписи). Середина тянется под длину текста.
- Тема — только данные: никакого CSS/JS. Лимит 100 МБ.
- Видеопетля: короткая (3–6 с), без звука и без альфа-канала, например
  `ffmpeg -i loop.mov -c:v libvpx-vp9 -crf 36 -b:v 0 -an -r 30 -vf scale=1280:-2 loop.webm`.
